# SA_G07

There's three directories for this project: 
    - bankdir
    - mbecdir  
    - storedir


To run each script individually, correspondent to each element of this eCommerce system, you should run the following commands:

    BANK:
    (assuming you're in it's respective directory)
        
        python3 bank.py [-p <bk-port>] [-s <auth-file>]

       --------------------------------------------------------------------------------
        PARAMETER DESCRIPTION:

        -p <bk-port>: The port that bank should listen on. The default is 3000.
        
        -s <auth-file>: Name of the auth file. If not supplied, defaults to bank.auth

        --------------------------------------------------------------------------------


    CLIENT (mbec):
    (assuming you're in it's respective directory)
        
        python3 mbec [-s <auth-file>] [-i <ip-bank-address>] [-p <bk-port>] [-u <user-file>] -a <account> -n <balance>
        
        python3 mbec [-s <auth-file>] [-i <ip-bank-address>] [-p <bk-port>] [-u <user-file>] -a <account> -d <amount>
        
        python3 mbec [-s <auth-file>] [-i <ip-bank-address>] [-p <bk-port>] [-u <user-file>] -a <account> -c <amount>
        
        python3 mbec [-s <auth-file>] [-i <ip-bank-address>] [-p <bk-port>] [-u <user-file>] -a <account> -g
        
        python3 mbec [-i <ip-store-address>] [-p <st-port>] [-v <virtual-credit-card-file>] -m <shopping-value>

       --------------------------------------------------------------------------------
        PARAMETER DESCRIPTION:

        -a <account>: The customer's bank account name. The format of the account is a 
        number, e.g., 55555.
        
        -s <auth-file>: The authentication file that bank creates for the mbec and store. 
        If -s is not specified, the default filename is bank.auth (in the current work-
        ing directory). If the specified file cannot be opened or is invalid, the mbec exits with a
        return code of 130.
        
        -i <ip-bank-address>: The IP address that bank is running on. The default value
        is 127.0.0.1.
        
        -p <bk-port>: The TCP port that bank is listening on. The default is 3000.
        
        -u <user-file>: The customer’s mbec user file. The default value is the account
        name prepended to .user (<account>.user). For example, if the account name
        was 55555, the default user file is 55555.user.
        
        -i <ip-store-address>: The IP address that store is running on. The default
        value is 127.0.0.1.
        
        -p <st-port>: The TCP port that store is listening on. The default is 5000.
        
        -v <virtual-credit-card-file>: The customer's mbec vcc file generated. The
        default value is the account name concatenated with a sequential number and prepended
        to .card (<account_seqNumber>.card). For example, if the account name was
        55555 and the sequential number was 2, the default vvc file is 55555_2.card.


        --------------------------------------------------------------------------------
        MODES OF OPERATION POSSIBLE:
        -n <balance> : Create a new account with the given balance. The account must be
        unique (i.e., the account must not already exist). The balance must be greater than or
        equal to 15.00. The given user file must not already exist. If any of these conditions do
        not hold, mbec exits with a return code of 130. On success, both mbec and bank print
        the account and initial balance to standard output, encoded as JSON with two string keys:
        account and initial_balance.
        Example: {"account":"55555","initial_balance":15.00}
        In addition, mbec creates the user file for the new account (think of this as like an autogenerated pin).

        -d <amount>: Deposit the amount of money specified. The amount must be greater
        than 0.00. The specified account must exist, and the user file must be associated with the
        given account (i.e., it must be the same file produced by mbec when the account was
        created). If any of these conditions do not hold, mbec exits with a return code of 130. On
        success, both mbec and bank print the account and deposit amount to standard output,
        encoded as JSON with two string keys: account and deposit.
        Example: {"account":"55555","deposit":20.00}

        -c <amount>: creates a virtual credit card with the amount of money specified. The
        amount must be greater than 0.00 and not exceed the current balance. The user file must
        be associated with the specified account (i.e., it must be the same file produced by mbec
        when the account was created). Also, it cannot exist an active virtual credit card for the
        current account. The mbec exits with a return code of 130 if any of these conditions are
        not true. On success, the vcc file is created with the name format specified above, where
        a sequence number is a number that starts at 1 when the bank is started and increments by
        one when a credit card is requested. In addition, both mbec and bank print the account,
        the credit card amount and the vcc file name to standard output, encoded as JSON with
        three string keys: account, vcc_amount, and vcc_file.
        Example: {"account":"55555","vcc_amount":12.00, "vcc_file":"55555_2.card"}

        -g : Get the current balance of the account. The specified account must exist, and the user file must be associated with the account. Otherwise, mbec exits with a return code of
        130. On success, both mbec and bank print the account and balance to stdout, encoded
        as JSON with two string keys: account and balance .
        Example: {"account":"55555","balance":43.63}
        -m <shopping-value> : Withdraw the amount of money specified from the virtual
        credit card and the bank account. The amount must be greater than 0.00 and cannot exceed the limit of the vcc. The vcc file must contain the necessary data to associate it to the
        right bank account. This operation has implicit by the store the verification of the credit card in the bank, i.e., if the credit card is active and the current account balance covers
        the amount of money specified. The mbec exits with a return code of 130 if any of these
        conditions are not true. On success, the account balance is updated and the vcc turns inactive. In addition, both mbec and store print the vcc reference and credit card amount
        used to standard output, encoded as JSON with two string keys: vcc_file and
        vcc_amount_used.
        Example: {"vcc_file":"55555_2.card","vcc_amount_used":7.00}
        --------------------------------------------------------------------------------


    STORE:
    (assuming you're in it's respective directory)
        
        python3 store.py [-p <st-port>] [-s <auth-file>]

       --------------------------------------------------------------------------------
        PARAMETER DESCRIPTION:

        -p <st-port>: The port that store should listen on. The default is 5000.

        -s <auth-file>: Name of the auth file. If not supplied, defaults to bank.auth
        --------------------------------------------------------------------------------
